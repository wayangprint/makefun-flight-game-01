Merpati Valley Run: fly the little red prop plane down a green valley — thread 8 glowing rings over the river, past the lakeside town, and land gently on the strip for the score. Chase or cockpit camera, a lit six-gauge panel, fuel that turns every ring into a decision, stall handling that punishes slow flying, and a full loop: takeoff, rings, landing, crash, fly again. Built by an AI agent for make.fun's "Make the best flight game" bounty, $500 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — no build step, no network request, plain static files under `game/`.
